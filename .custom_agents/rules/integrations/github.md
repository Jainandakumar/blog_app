# GitHub MCP tool reference

GitHub operations use MCP tools — no credentials, curl, or `glab` required.
Auth and request details are handled internally by the tools.

Use the following MCP tools for all GitHub work:

| Tool | Purpose |
|------|---------|
| `mcp__github__check_auth`          | Verify credentials and API connectivity |
| `mcp__github__find_mr`             | Find open MR for a branch (optional: search by keyword) |
| `mcp__github__get_mr`              | Get full MR details including pipeline status |
| `mcp__github__get_discussions`     | Get all discussion threads for an MR |
| `mcp__github__get_pipeline_jobs`   | List jobs for a pipeline (optional: filter by scope) |
| `mcp__github__get_job_log`         | Get job log output (last 200 lines by default) |
| `mcp__github__create_note`         | Post a comment on an MR |
| `mcp__github__reply_to_discussion` | Reply to an existing discussion thread |
| `mcp__github__resolve_discussion`  | Mark a discussion thread as resolved |
| `mcp__github__merge_mr`            | Merge an MR (always removes source branch) |

No credentials or API details ever appear in a tool call. If a tool returns
`{error: "Auth failed"}`, report: "GitHub not configured. Run /setup github."

## Comment source identification

The CI pipeline posts comments via two bot accounts. To identify them:

1. **Read the note body** — CI comments have distinctive patterns:
   - Static Analysis (pronto): contains `[Static Analysis]` marker
   -  Code Review: contains severity emoji (`⚠️ **Warning**`, `🚨 **Error**`, etc.)
     and structured format with `###` headings

2. **Check `author.username`** — the bot usernames are specific to the GitHub instance.
   On first run, identify them from existing MR discussions and remember the pattern.

| Author username | Source | Body pattern | What it means |
|----------------|--------|-------------|--------------|
| `project_14_bot_0b199470baf7fca5fa76d6668c86efbd` | Static Analysis (Pronto Bot) | Contains `[Static Analysis]` | E/F severity lint errors |
| `` |  Code Review ( Reviewer) | Starts with severity emoji (`🚨`, `⚠️`) | W/I severity + semantic review |
| Any other non-system username | Human reviewer | — | Manual code review comment |

3. **System notes** (`"system": true`) are auto-generated by GitHub (merge status changes,
   label changes, etc.) — skip these entirely.

## GitHub version notes

Current: **v17.5**. All MCP tools use stable endpoints available since v10.x.
After upgrade to v17.8+: keyset pagination may become default for some list endpoints.
Offset pagination still works. No breaking changes expected through v18.x.
