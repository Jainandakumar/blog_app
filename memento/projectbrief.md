# Project Brief

## Project Name
Blog App

## Overview
A Ruby on Rails 7.2 blog application where users can create posts and add comments to posts.

## Core Requirements
1. Users can be created and managed (name, email)
2. Users can create blog posts (title, body, authored by a user)
3. Anyone can add comments to a post (body text)
4. Comments are nested under posts
5. Full CRUD for posts; create and delete for comments

## Goals
- Simple, clean blog functionality
- Standard Rails MVC architecture
- SQLite database (development)
- Minimal, readable CSS styling (no external CSS framework)
